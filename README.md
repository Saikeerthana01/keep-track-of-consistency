# Study Tracker Calendar

This is a web-based study consistency calendar web app that allows users to:

- Mark study days as green (studied) or red (missed)
- Clear a day if marked by mistake
- See monthly consistency analysis
- Choose different background images and calendar styles
- Navigate between months

## Important Note
The entire code for this project was generated with the assistance of AI (ChatGPT).

## Usage
- Open the live link: https://your-username.github.io/your-repo/
- Select a day and mark it green or red
- Clear a day using the “Clear Day” button
- Review monthly consistency analysis
